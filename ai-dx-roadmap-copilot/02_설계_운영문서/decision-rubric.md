# 우선순위 루브릭

## 점수 항목

각 후보는 1~5점으로 평가한다. 점수는 실제 industrial-automation 조직 평가가 아니라 설명 가능한 포트폴리오용 예시다.

| 항목 | 가중치 | 질문 |
|---|---:|---|
| 전략 적합도 | 25% | DT 공고의 전략·로드맵·혁신 과제와 얼마나 직접 연결되는가? |
| 사업 영향 | 25% | 시간·품질·비용·의사결정에 기대되는 영향은 무엇인가? |
| 실행 가능성 | 15% | 1인 프로젝트 MVP로 범위를 통제할 수 있는가? |
| 데이터 준비도 | 15% | 공개·합성 데이터로도 검증 가능한가? |
| 시급성 | 10% | 지금 검토할 이유와 재검토 주기가 있는가? |
| 거버넌스 준비도 | 10% | 사람 승인, 책임자, 예외, 감사 이력을 설계할 수 있는가? |

기본 점수는 다음과 같다.

```text
점수 = 20 × Σ(각 항목 점수 × 가중치)
```

기존 포트폴리오와 중복 위험이 높으면 별도 표시하고 점수에서 최대 8점을 감점한다. 단, 점수 감점보다 중요한 규칙은 기존 프로젝트를 `eligibleForNextProject=false`로 분류해 신규 프로젝트 순위에서 제외하는 것이다.

## KPI 규칙

- 기준값이 있으면 목표값과 측정주기를 사람이 검토한다.
- 기준값이 없으면 `baseline_required`를 반환한다.
- KPI 초안은 선행 지표와 결과 지표를 모두 포함한다.
- KPI가 좋아져도 안전·품질·규정 위반이 있으면 성공으로 확정하지 않는다.

## 판단 한계

가중치와 점수는 설명 가능성을 위한 초안이다. 실제 조직에서는 담당자 인터뷰, 업무 로그, 비용, 보안, 규제, 변화관리 조건을 추가 확인해야 한다.
