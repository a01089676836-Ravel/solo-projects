# 아주 쉽게 이해하기

## 한 문장

여러 AI 아이디어 중에서 **무엇을 먼저 만들지 골라주고, 실행계획과 성과 측정 방법까지 정리해주는 회사용 도구**다.

## 무엇을 넣나

예를 들어 다음과 같은 AI/DX 아이디어를 넣는다.

- 문서 업무 자동화
- 업무 프로세스 개선
- 스마트에너지 운영
- AI/DX 신기술 조사

각 아이디어에는 문제, 기대효과, 필요한 데이터, 담당자, 근거자료를 적는다.

## 무엇을 하나

1. 아이디어마다 점수를 계산한다.
2. 점수가 높은 순서대로 보여준다.
3. 30일·60일·90일 실행계획을 만든다.
4. 어떤 성과를 측정할지 KPI 초안을 만든다.
5. 최종 결정은 사람이 승인한다.

같은 실행 요청이 네트워크 재시도로 다시 들어오면 `Idempotency-Key`를 확인해 같은 결과를 재사용한다. 같은 키로 다른 내용을 보내면 충돌로 거부한다.

## KPI는 무엇인가

KPI는 “잘 되고 있는지 확인하는 숫자”다.

예를 들면 “업무 처리시간”이나 “파일럿 승인까지 걸린 일수”다. 현재 기준값을 모르면 AI가 목표 숫자를 마음대로 만들지 않고 `baseline_required`라고 표시한다.

## Copilot은 무엇인가

보안 제품이나 특정 회사 서비스가 아니다. AI가 초안을 만들어 주고 사람이 최종 결정하는 **의사결정 보조 역할**이라는 뜻이다.

## 현재 상태

- 지금은 회사 내부 데이터가 아닌 합성 예시로 작동한다.
- 현재는 외부 API를 호출하지 않는다.
- 따라서 아직 상용 제품은 아니며, 상용화를 위한 첫 번째 검증 단계다.
- 현재 로컬 파일럿에는 개발용 로그인 경계, 감사 기록, 웹 화면, 후보·근거·KPI 입력이 들어 있다. 상용 전에는 데이터베이스, 기업 로그인·권한, 실제 커넥터와 운영 검증으로 교체·확장해야 한다.

## 기존 프로젝트와의 차이

- 기존 프로젝트: 설비 이상을 찾고 유지보수 방법을 제안하는 기술 프로젝트
- 새 프로젝트: 여러 AI/DX 과제 중 무엇을 먼저 추진할지 결정하는 전략·운영 프로젝트

두 프로젝트를 합치면 “AI를 만들 수 있고, 어떤 AI를 먼저 도입할지도 판단할 수 있다”는 포트폴리오가 된다.
