## KPI 초안

### 1. AI·DX 과제 발굴·우선순위·로드맵 Copilot
- 목적: 아이디어 접수부터 파일럿 승인까지의 의사결정 품질과 리드타임을 개선한다.
- 선행 KPI: 근거·데이터 준비도·담당자가 채워진 과제 카드 비율
- 결과 KPI: 과제 접수부터 파일럿 승인까지의 평균 리드타임
- 기준값 상태: **baseline_required**
- 목표값: 기준값 측정 후 사람 승인

### 2. AX 업무 프로세스 최적화·거버넌스 Agent
- 목적: 반복 업무의 수작업 인계와 승인 지연을 줄이면서 통제 가능성을 유지한다.
- 선행 KPI: 프로세스별 책임자·승인 게이트·예외 규칙이 정의된 비율
- 결과 KPI: 표준 프로세스의 처리 리드타임 또는 수작업 인계 횟수
- 기준값 상태: **baseline_required**
- 목표값: 기준값 측정 후 사람 승인

### 3. AI/DX 트렌드·선진사 벤치마킹 Radar
- 목적: 트렌드 발견부터 내부 적용 후보로 검토하기까지의 시간을 단축한다.
- 선행 KPI: 1차 출처와 적용 조건이 기록된 트렌드 카드 비율
- 결과 KPI: 벤치마킹 결과에서 파일럿 검토로 전환된 비율
- 기준값 상태: **baseline_required**
- 목표값: 기준값 측정 후 사람 승인

## 사람 검토 체크리스트

- [ ] 공고·회사 자료와 후보 과제의 연결 근거 확인
- [ ] 점수 가중치와 과제 입력값 검토
- [ ] 실제 기준값과 데이터 소유자 확인
- [ ] KPI 목표값·측정주기·예외 기준 승인
- [ ] 파일럿 종료·확대·중단 조건 기록

## 제한사항

- 후보 과제, 점수, KPI 기준값은 합성 픽스처다.
- industrial-automation 내부 데이터·성과·조직 담당자를 검증하지 않았다.
- 가중치는 설명 가능한 예시이며 실제 조직 의사결정 전에 사람이 조정해야 한다.
- 현재 LLM이나 Astra API를 호출하지 않았으므로 생성형 모델 품질은 검증하지 않았다.
