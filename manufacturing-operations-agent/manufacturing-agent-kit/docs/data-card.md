## 실험 결정

정상 train 5,745행에서만 평균과 모집단 표준편차를 계산한다. 비교 방법은 변수별 절대 z 점수의 최댓값과 z 제곱의 평균이다. 둘 다 동일한 입력·분할을 쓴다. 정상 validation 점수의 95백분위(최근접 순위)를 초과하면 알림으로 간주한다. 5%는 실험 전 선택한 정상 validation 알림 예산이며 사업 요구사항이나 test 오경보 보장이 아니다.

고장 라벨은 정상 학습·보정 표본 선택과 평가에 사용하므로 완전 비지도 학습이라고 부르지 않는다. 유형 플래그로 고장 생성 공식을 재현하지 않았다. 평가 결과를 본 후 test에 맞춘 임계값 변경이나 최적 방법 선정은 하지 않는다. 이후 개선은 train/validation에서 수행하고 새로운 최종 보류 데이터 확보를 검토한다.
