# 프로젝트의 목적 — 2026-09-07 사용자 설명 반영

통계·데이터 전공으로 분석 코드를 접했지만 개발 중심 코드의 구조와 방법을 선택한 이유를 판단하는 데 어려움을 느꼈다. 제조 AI 교육 과정DX 관련 경험과 채용설명회를 통해 AI 업무 위임의 의도와 검증이 중요함을 인식했고, 이를 직접 경험하려 한다. 구체적인 제조 현장 문제를 직접 겪었다는 주장은 하지 않는다.

학습 목적: 목적·제약·완료 기준을 정의하고 AI에게 맡긴 결과를 근거로 판단·수정하는 경험을 쌓는다.

탐구 질문: 지시 방식에 따라 결과의 적합성, 오류, 수정 부담이 어떻게 달라지는가? 좋은 설명과 검증된 결과를 어떻게 구분하는가?

제조 프로젝트의 역할: AI 추천으로 시작한 실제 개발 연습 대상. 이미 구현된 기준선·저장/API·화면은 유지하고 다음 기능에서부터 학습 흐름을 적용한다. 제조 도메인 유효성과 현업 수요는 아직 별도 검증 대상이다.

Opal의 역할: 위임 카드를 만들고 실제 결과를 완료 기준과 대조하는 비서. AI 선택의 필요와 한계도 평가한다. 앱 자체는 아직 미구현이다.

다음 실행 초안: SOP 검색 기능의 설계 과제 하나에서 지시 방식 A/B를 비교하고 사용자가 선택 이유·검증 방법을 직접 설명한다. 이는 제안 계획이며 아직 비교 결과나 사용자 이해도 평가가 없다.
