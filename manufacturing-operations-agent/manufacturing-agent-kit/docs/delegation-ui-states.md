# 위임 카드: 화면의 빈 목록·실패·재시도 검증

- 사용자 요청: 1인 프로젝트를 토큰 최소화 스킬과 함께 지금 진행.
- 확인된 사실: 기존 UI·API·피드백 구현 완료. STATE.md에 브라우저 오류 주입 검증이 남아 있음.
- Codex 선정 과제·목적: 사용자가 알림 없음과 조회 불가를 구별하고 재시도할 수 있는지 확인.
- 학습 질문: API 검사 통과만으로 화면의 실패 대응까지 검증됐다고 할 수 있는가?
- 입력: 수정하지 않은 src/ui.html, 통제된 200 빈 응답 및 503 응답.
- 제약: 별도 localhost 서버, DB 접근 없음, 실제 장애·작업자 평가로 표현하지 않음.
- 산출물: 재현 가능한 개발 서버와 실제 브라우저 관찰 기록.
- 완료 기준: 빈 목록 문구, 오류 및 재시도 안내, 오류 후 새로고침으로 정상 빈 목록 복구, 이전/다음 비활성화, 상세 숨김.
- AI 역할: 검증 환경 작성·실행·화면 관찰·결과 기록.
- 사람이 판단할 항목: 문구가 두 상황을 충분히 구별하는지. 사용자 이해도는 직접 답변 전까지 미평가.
- 도구 선택: 기존 Node와 Chrome으로 실제 UI 확인 가능. 새 패키지·유료 호출·모델 비교 불필요.
