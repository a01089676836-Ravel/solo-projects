# industrial-automation DT 직무 연계 1인 프로젝트 후보

작성일: 2026-09-22

이 문서는 현재 제조 이상탐지 Agent 프로젝트 다음에 수행할 수 있는 industrial-automation DT 직무 연계 후보를 정리한 것이다. industrial-automation의 공식 자료에서 확인되는 `Futuring Smart Energy`, 전력·자동화, DX 솔루션, AI·디지털 기반 혁신과 연결하되, 특정 프로젝트가 채용이나 합격을 보장한다고 해석하지 않는다.

## 현재 프로젝트의 강점과 남은 공백

현재 프로젝트는 센서 데이터 구조화, 이상탐지 기준선, SQLite/API, Agent 근거 검증, 안전 권한 분리, fallback, 사람 승인과 회복 재검증을 보여준다. 반면 DT 직무 관점에서 다음 세 가지는 별도 산출물로 보강할 수 있다.

1. 전사 DX 과제를 발굴하고 우선순위를 정하는 기획 관점
2. 전력·스마트에너지·자산 운영으로 확장하는 도메인 관점
3. 업무 프로세스 최적화와 AI 사용 거버넌스를 설계하는 관점

## 추천 후보 3개

## 1순위 추천

현재 제조 이상탐지 프로젝트와 가장 덜 겹치면서 DT 기획 역량을 보완하는 것은 **1번 AI·DX 과제 발굴·우선순위·로드맵 Copilot**이다. 기존 프로젝트가 “센서 데이터가 운영 판단으로 이어지는 방법”을 보여준다면, 1번은 “어떤 업무 문제를 디지털·AI 과제로 선택하고 어떻게 실행 기준을 세우는가”를 보여준다.

권장 연결 순서는 다음과 같다.

```text
기존 프로젝트: 데이터·이상탐지·Agent 신뢰성
  → 1번: DX 과제 선정·로드맵·KPI
  → 2번: 스마트에너지 운영 사례
  → 3번: 업무 적용·거버넌스·사람 인계
```

처음부터 세 개를 동시에 만들지 않고 1번의 작은 수직 기능 하나를 완성하는 편이 좋다. 최소 완료 기준은 입력 스키마, 우선순위 규칙, 근거 링크, 사람이 수정한 기록, 동일 사례 재실행, 실패·보류 사례, README와 한계 문서다.
