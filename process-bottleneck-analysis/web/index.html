데이터 불러오는 중

단일 생성·입고·송장·지급 기록이 있는 사례를 비교합니다.

비교 가능한 구매 항목—주문 문서가 아닌 항목 기준
처리 경과시간 중앙값—항목 생성 → 지급 기록
상위 10% 경계 · P90—관측된 사례의 시간 분포
가격 변경 기록 비율—오류·재작업으로 확정하지 않음

가장 자주 나타난 처리 경로

비교 코호트에서 가장 빈번한 경로 하나입니다. 전체 업무는 여러 경로로 진행됩니다.

관측된 사실

병목 조사 후보

누적 사례·일 순서입니다. 경과시간에는 지급조건에 따른 정상적인 기간도 포함될 수 있습니다. 행을 선택하면 원본 사례를 확인합니다.

    어떤 사례가 제외되었나요?

    제외 조건 · 중복 집계사례 수

    반복 입고·송장·지급은 정상 분할 처리일 수 있습니다. 제외된 사례를 불량 업무로 해석하지 않습니다.
