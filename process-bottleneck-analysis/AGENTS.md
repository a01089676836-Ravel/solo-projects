# 프로젝트 작업 지침

- 한국어 먼저 응답하고 English에는 자연스러운 요청 표현과 핵심 답을 덧붙인다.
- 사용자가 요청한 evidence-traceability 및 기본 token-efficient-quality 스킬을 적용한다.
- 먼저 STATE.md와 현재 수정에 관련된 파일만 읽는다.
- 공개 BPI 2019 로그를 분석하는 프로젝트다. 기업 내부 데이터·반도체 공정·현장 실적이라고 표현하지 않는다.
- 원본은 수정하지 않는다. 사례를 샘플링할 때는 이벤트 행이 아닌 전체 case 단위를 유지한다.
- 중복 후보를 임의 삭제하지 않는다. 분할 입고·송장·지급을 재작업 또는 오류로 단정하지 않는다.
- 지표 변경 시 분모·코호트·시간 기준·누락 및 동시각 처리 규칙을 docs/metrics-and-decisions.md에 기록한다.
- 관측 결과, 추정, 개선 가정을 구분한다. 시뮬레이션 수치를 실제 절감으로 표현하지 않는다.
- 코드/지표 변경에 필요한 자동 검증을 실행하고 실제 결과를 reports와 STATE.md에 남긴다.
- 외부 사용자 업로드, LLM 연결, 외부 배포, 기존 프로젝트 수정은 현재 범위에 포함되지 않는다.
- 브라우저 연결이 없으면 시각 검수 완료로 표시하지 않는다.
