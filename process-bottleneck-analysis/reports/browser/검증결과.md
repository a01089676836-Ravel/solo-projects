# 대시보드 최종 디버깅·브라우저 검증 — 2026-09-25

사용자가 Playwright 검증을 명시적으로 요청했다. 기존 CUA 도구는 Transport closed 상태였으므로 설치된 Google Chrome을 별도 headless 세션으로 실행했다. 사용자의 원래 Chrome 탭은 조작하지 않았다.

## 결과

**실제 Chrome 브라우저 검사 10/10 통과.** Chrome 153.0.8010.53, Playwright Core 1.63.0. 데스크톱 1440×1000과 모바일 폭 390×844에서 실행했다. 실제 모바일 기기·Firefox·Safari 검증은 수행하지 않았다.

## 발견한 문제와 수정

1. 검색어 앞뒤 공백을 그대로 비교하여 `  invoice  `가 결과를 찾지 못함 → 공백 제거 후 비교.
2. 이전 사례 조회의 실패가 늦게 도착하면 최신 성공 화면에도 오류를 표시함 → 요청 순번으로 성공·실패 응답 모두 최신 요청만 반영.
3. 재시도 성공 후 오류 메시지가 남고, 로딩 중 이전 사례 타임라인이 보임 → 새 요청 시 오류·이전 타임라인 초기화 및 로딩 상태 표시.
4. 타임라인에 순번이 두 번 표시됨 → 목록 번호 하나만 사용.
5. 왼쪽 선택 구간과 오른쪽 시나리오 기준 구간을 혼동할 수 있음 → 시나리오가 고정 분석 기준 구간에 적용됨을 명시.

수정 전 추가 DOM 회귀 검사 7개 중 3개가 실패했고, 수정 후 7/7 통과했다. 기존 Python 로직·HTTP 검사 17/17 및 독립 데이터 검증 11/11도 통과했다.
