## 미완료 / 주장하지 않는 것

- 기존 CUA 연결은 Transport closed 상태. 사용자가 명시적으로 승인한 별도 Playwright Chrome으로 렌더링·검색·사례 선택·시나리오 변경 검증 완료. 사용자가 열어 둔 Chrome 탭과 실제 모바일 기기·다른 브라우저 검증은 범위 밖.
- PM4Py 기반 모델 발견·정합성 검사, 예측 모델, LLM 연결, 기업 시스템 연계는 미구현.
- 금액 대사·완납 검증·계약 지급조건 판단·실제 절감 성과는 미검증.
- 현장 담당자 인터뷰·사용성 평가·전후 개입 실험은 미수행.
