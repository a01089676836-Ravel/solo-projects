# 설계·데이터 사전·가정

## 문제 범위와 완료 기준

제품 단위 공정 이력이 분석·검사 우선순위·공정 개선 실험으로 이어지는 소규모 시스템입니다. 완료 기준은 (1) 원본 생성과 분석 재현, (2) 손상 데이터 거부, (3) 시간순 시험, (4) 두 직무의 화면과 설명, (5) 경량 추론과 sklearn 점수 일치, (6) 모의 실험의 원시 결과 공개입니다. 현장 성능 인증이나 실물 생산라인 구축은 범위에 포함하지 않습니다.

## 공정과 시간

- 교육용 전동화 부품: 체결 FASTEN → 접합 WELD → 밀봉 측정 SEAL → 최종 검사 EOL.
- 30개 일자, 일자당 180개 투입, 70초 간격, 순생산 구간 12,600초(210분).
- 시간은 각 일자 시작 기준 초입니다. 구간 뒤에 완료한 부품도 품질 통계에는 포함합니다.
- FIFO, 선행 공정 완료 후 다음 공정 시작, 셀은 한 번에 한 부품만 처리합니다.
- 공정 간 버퍼는 무한, 이송시간은 0, 설비 고장·교대·보전·작업자 공용 자원은 없습니다.
- 기본 작업시간은 44/53/38/78초에 사양별 추가시간과 난수 변동을 더합니다. 전부 작성자가 정한 가정입니다.
- EOL 최초검사 불합격품에는 20초 진단시간이 추가되며 보류됩니다. 재작업 합격을 가정하지 않습니다.
- 공정 모델은 배터리 전기화학·고전압 안전성 모델이 아닙니다. 토크와 압력 등의 수치를 실제 설비 설정값으로 사용하면 안 됩니다.

## 불량 생성과 예측의 한계

불량은 체결·접합·밀봉 편차, 진동, 미관측 교란과 Bernoulli 난수를 조합한 가상 생성식으로 정합니다. 사양 구성은 고정 확률이며 25일 이후에는 작은 체결 편향이 추가됩니다. 생성식은 `factorylab/simulation.py`에 공개했습니다.

현재 시드는 시험 불합격률 약 29%의 결함 다발 스트레스 시나리오입니다. 실제 공장의 정상적인 불량 빈도로 해석하지 않습니다. 낮은 불량률 환경의 별도 실험은 후속 과제이며, 보기 좋은 시험 점수를 얻기 위해 시드를 골라 바꾸지 않았습니다.

학습 1–18일, 검증 19–24일, 시험 25–30일로 나눕니다. 표준화의 평균/표준편차와 입력 허용범위는 학습 데이터로만 구합니다. 가중 로지스틱 회귀 하나를 사전 선택했고 시험 성능을 보고 모델을 고르는 탐색은 하지 않습니다. 클래스 가중치가 있으므로 출력은 **보정된 확률이 아닌 위험 점수**입니다.

검증 Recall 0.80 이상 후보 중 검토율이 가장 낮은 임계값을 선택합니다. 추가 점검 용량 30%는 별도 평가 조건입니다. Recall 목표를 만족하더라도 용량을 초과하면 운영 가능한 정책이라고 결론 내리지 않습니다. 놓친 불량 비용 20, 과잉 검토 비용 1의 지표는 가정이며 임계값 선택에 쓰지 않습니다.

AP(average precision), Precision, Recall, F1, 혼동행렬, 검토율을 기록합니다. 무작위 순위 참고값은 불량 비율입니다. 전체 정상/전체 추가점검 기준도 비교합니다. 시험 일자 6개를 블록으로 300회 복원추출한 구간은 표본이 적고 생성식이 고정되어 있으므로 현장 일반화의 증거가 아닙니다.

**생성식이 알고 있는 편차를 특징으로 설계했으므로 높은 성능이 나와도 현실 문제를 해결했다는 뜻은 아닙니다.** 실제 데이터에서는 측정시점, 레이블 지연, 공정 변경, 결측, 센서 오차와 부품 계보를 다시 검증해야 합니다.

## 공정 개선 실험

| 대안 | 바꾸는 것 | 고정하는 것 |
|---|---|---|
| 기준 | 없음 | 1 EOL 셀, 기본 편차 |
| 병렬 검사 | EOL 셀 1→2 | 검사 시간·검사 정확도·제품 특성 |
| 편차 축소 | 체결·접합 편차를 0.55배 | 셀 수·투입 간격 |
| 결합 | 위 두 개입 | 나머지 모형 |

30개의 시드 각각에서 네 대안을 실행합니다. 같은 시드는 같은 사양·측정 오차·불량 난수를 사용합니다. 편차 축소에 따른 불량 감소는 생성식에 심어진 관계이며 현장 인과 효과의 실증이 아닙니다. 병렬 검사 자체는 품질을 바꾸지 않습니다.

완료량/구간 내 합격품/전체 최초검사 합격률/P95 리드타임/초과시간을 공개합니다. 차이의 95% 구간은 `평균차 ± 1.96 × 차이의 표본표준편차 / sqrt(30)`입니다. 이는 반복 모의 실험의 평균 오차 근사치로, 작업장 모델 불일치·가격·인력·안전·운영 제약을 포함하지 않습니다. OEE는 필요한 손실시간 정의가 충분하지 않아 산출하지 않습니다.

## 경량 추론과 워크플로

JSON 계수에 변환 규칙·표준화값·임계값·학습 범위를 기록합니다. 표준 라이브러리만으로 동일 점수를 계산하고 sklearn 결과와 대조합니다. 로컬 지연시간은 warm 호출의 특징 계산+추론+기여도 계산만 측정합니다.

입력 누락/비유한 값/미지 사양 → INSUFFICIENT_DATA, 학습 범위 외 → OUT_OF_DOMAIN입니다. 정상 범위 안에서도 정답을 보장하지 않습니다. 출력의 상위 log-odds 기여도는 가중치 기반 설명이며 근본 원인의 증명이 아닙니다.

SOP 번호는 프로젝트 내부 교육용 관리계획입니다. 실제 회사 표준이나 공인 규격이 아닙니다. 워크플로는 검증→병목 후보→개선안→검토 용량→담당자 검토를 연결하는 결정 규칙이며, 실제 LLM 에이전트는 연결되지 않았습니다.
