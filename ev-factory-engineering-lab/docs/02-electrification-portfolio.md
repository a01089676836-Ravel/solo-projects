# 프로젝트 02 · 전동화 조립공정 병목·품질 개선 실험

## 한 문장

체결–접합–밀봉검사–EOL로 구성한 가상 부품 조립 라인에서 생산 병목을 확인하고, 검사 셀 증설과 공정 편차 감소의 효과를 비교하는 공정 설계 실험.

## 보여줄 역량

| 영역 | 구현 | 근거 |
|---|---|---|
| 공정 이해의 기초 | 선행관계, 셀 점유, 투입 간격, 사양 차이 | factorylab/simulation.py |
| 생산성 분석 | CT/택트 비교, 대기, P95 리드타임, 구간 내 완료량 | output/stations.csv, 대시보드 |
| 설비 대안 검토 | EOL 1셀/2셀 자원 비교 | output/scenarios.csv |
| 품질·공정 연결 | 체결·접합 편차와 최초검사 불합격의 가정된 관계 | 시뮬레이터 및 관리계획 |
| 실험 검증 | 공통 난수를 사용한 30쌍 비교, 개별 실험과 구간 공개 | output/experiment_runs.csv |

설비 설계 도면, PLC 로직, 실제 공법 개발, 실물 배터리 시험, 현장 안전 검증은 구현하지 않았습니다. 본 프로젝트는 데이터 분석 전공자가 생산기술 문제를 이해하고 실험하는 입문용 포트폴리오입니다.

## 3분 시연 순서

1. 공정별 평균 CT에서 가정 택트 70초를 넘는 EOL을 확인합니다.
2. 개체 이력에서 실제로 EOL 대기가 누적되는지 봅니다.
3. EOL 셀만 늘리는 대안과 측정 편차만 줄이는 대안을 비교합니다.
4. 완료량과 합격률의 변화가 서로 같지 않음을 설명합니다. 검사 셀 증설 자체는 불량 생성식을 바꾸지 않습니다.
5. 결합 개선의 평균과 95% 구간을 제시하되, 실제 설비 성과로 주장하지 않습니다.
6. 관리계획에서 어떤 특성을 기록하고 어떤 근거로 담당자 검토로 넘기는지 설명합니다.

## 개선 의사결정 메모

- 관찰: 실제 모의 결과는 `output/RESULTS.md`에서 확인합니다.
- 설명: EOL 자원 부족에 따른 대기와 공정 편차에 따른 불합격은 별도 메커니즘입니다.
- 검증: 같은 제품·난수 조건에서 대안을 비교하여 모형 안의 차이를 확인합니다.
- 미확인: 검사 셀 설치비, 공간, 작업자, 유한 버퍼, 물류·장비 고장, 실제 편차 축소 방법과 비용.
- 다음 실험: 유한 버퍼와 설비 중단을 추가하고 대안의 우위가 유지되는지 확인합니다.

## 자기소개서용 문장 초안

직접 실행·설명할 수 있게 된 내용에 한해 사용합니다.

> 전동화 생산기술 업무를 이해하기 위해 가상의 부품 조립 라인을 구성하고, 공정별 작업시간과 대기시간을 구분해 병목을 분석하는 프로젝트를 학습했습니다. 검사 셀 증설과 체결·접합 편차 축소를 별도 대안으로 두고 같은 난수 조건의 반복 실험으로 비교했습니다. 생산량과 품질의 변화가 다른 이유를 확인하며, 개선안의 효과뿐 아니라 설비·인원·현장 조건 등 아직 반영하지 않은 제약도 함께 설명하려고 했습니다.

30쌍 모의 실험은 실제 제조업 개선 실적이 아닙니다. 공정 전문가에게 가정을 검토받거나 실물 데이터를 연결한 이후에는 해당 단계의 증거를 별도로 기록합니다.
