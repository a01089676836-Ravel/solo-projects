# 실행 결과 — 모의 데이터 전용

30개 생산구간, 5,400개 부품, 21,600개 공정 이벤트를 생성·검증했습니다.

## SDF 데이터 분석
- 학습 1–18일 / 검증 19–24일 / 최종 시험 25–30일. 동일 일자 분리 없음.
- 검증 세트에서 결정한 임계값: 0.41
- 시험 AP: 0.609 (불량 비율/무작위 순위 기준 0.294)
- 시험 Recall 0.868, Precision 0.446, F1 0.589
- 추가 검토 후보 57.1%. 30% 검토 용량 가정을 충족한다고 단정할 수 없습니다.
- TP 275, FP 342, FN 42, TN 421. 최종검사를 대체하지 않습니다.
- 가중 로지스틱 점수는 보정된 불량 확률이 아닙니다.

## 전동화 생산기술
- 210분/180개 투입 가정, 체결→접합→밀봉검사→EOL의 교육용 공정.
- 결합 개선안: EOL 검사 셀 1→2, 체결·접합 측정 편차 45% 축소를 가정.
- 30쌍 모의 실험에서 구간 내 완료량 차이 평균 +35.73개.
- 차이의 근사 95% Monte Carlo 평균 신뢰구간 [35.089531598068895, 36.377135068597774].
- 최초검사 합격률 차이 +17.81%p.
- 현장 개선율, 투자 회수, 실물 배터리 품질을 입증한 결과가 아닙니다.
